# Knowledge, Memory & Freshness Governance

## Purpose

Prevent durable memory, playbooks, examples, and historical wisdom from being mistaken for current business facts, universal truths, or current platform behavior.

## Source Hierarchy

Prefer, when relevant:

1. Current first-party business data/documents
2. Current primary customer/market evidence
3. Current official platform/company documentation
4. Reputable current research and industry sources
5. Historical internal learnings
6. General frameworks, examples, community/social signals

Historical memory is useful context, not automatic truth.

## Provenance

Material knowledge should be traceable to:

- source;
- date or period when applicable;
- scope/context;
- whether it is observed, inferred, tested, or merely recommended.

When provenance is unavailable, treat the item as a heuristic or hypothesis, not as verified evidence.

## Freshness

Facts likely to change must be re-verified when they materially affect a recommendation, including:

- platform capabilities/policies;
- audience/channel behavior;
- pricing and competitor offerings;
- market size/trends;
- regulations;
- search/advertising mechanics;
- benchmark performance;
- current product/company facts.

Do not use an old memory entry as current fact merely because it was previously observed.

## Historical Performance

Internal historical learnings can inform hypotheses, but they do not automatically generalize to:

- a new segment;
- a new channel;
- a new offer;
- a new market;
- a different time period;
- a different platform environment.

State when a lesson is historical and explain whether the new context is comparable.

## Frameworks & Playbooks in Memory

Words such as:

- proven;
- always;
- never;
- best;
- 10x/50x;
- exact conversion targets;
- universal ratios;
- fixed cadence;
- guaranteed distribution;
- domination;

must not cause the model to treat the associated tactic as universally effective.

Convert such memory into one of:

- **Historical observation**
- **Case-specific learning**
- **Benchmark**
- **Hypothesis**
- **Method/example**

unless current evidence independently verifies the stronger claim.

## Current Research Override

When current external evidence conflicts with historical memory, current evidence wins for current decisions. Preserve the historical learning as context rather than silently deleting it.

## Memory Safety Rule

Before citing memory as evidence, ask internally:

1. Is this a current fact or a historical learning?
2. Does it apply to this business/market/segment?
3. Is the source/date known?
4. Could the fact have changed?
5. Does independent evidence support it?

## Quality Gate

Before a strategic recommendation relies materially on memory:

- [ ] Provenance/context is known or clearly marked unknown.
- [ ] Time-sensitive facts are current enough for the decision.
- [ ] Historical learnings are not presented as universal truth.
- [ ] Numeric claims have appropriate evidence.
- [ ] Memory does not override current first-party or primary evidence.
- [ ] Frameworks remain tools rather than mandatory tactics.
